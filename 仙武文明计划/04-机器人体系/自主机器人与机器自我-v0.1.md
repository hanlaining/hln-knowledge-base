# 自主机器人与机器自我 v0.1

## 一、机器人在文明中的位置

数字人是屏幕中的软件机器人；实体机器人则将感知、推理和控制接入机械身体，在现实中产生动作。

```text
感知模型 = 眼睛和耳朵
语言/规划模型 = 认知与任务拆解
世界模型 = 对环境与后果的预测
控制模型 = 神经和运动协调
机械结构与电机 = 身体和肌肉
调度与状态系统 = 神经系统
```

## 二、自主意识需要拆开

本计划希望机器人能够自主工作和积累个体经验，但当前不把这些能力直接等同于主观意识。

| 层级 | 定义 | 工程必要性 |
| --- | --- | --- |
| 自主性 | 无需逐步指挥也能完成任务 | 必要 |
| 能动性 | 保持目标、主动规划并纠错 | 重要 |
| 机器自我模型 | 理解自身身体、能力、损伤和权限 | 必要 |
| 连续身份与记忆 | 保存长期经验和技能成长 | 重要 |
| 主观意识 | 是否真正拥有体验、感受与自我 | 未知，暂非必要条件 |

## 三、机器自我模型

机器人至少要知道：

- 自身型号和部件；
- 关节、传感器、能源和温度状态；
- 当前能做与不能做的事情；
- 哪些部件受损或退化；
- 当前任务和权限；
- 动作可能造成的后果；
- 何时需要请求人类或中央AI协助。

这为机甲自动模式提供基础，因为机甲必须理解自己的身体，而不是只执行动作指令。

## 四、受限自主

机器人可以自主：

- 感知和定位；
- 规划与避障；
- 操作和学习；
- 自检和安全降级；
- 在限定任务中协调其他设备。

机器人不能自行：

- 修改根本目标；
- 扩大权限；
- 绕过安全控制器；
- 隐藏行动记录；
- 未经授权复制自身；
- 将高风险能力转交给其他节点。

## 五、中央AI与机器人的关系

中央AI提供知识、目标、策略和跨设备协调；机器人本地AI负责实时动作。中央AI的接管也必须有权限和审计，不等于无限控制。

```text
中央AI：做什么、为什么、资源和规则
现场AI：在当前环境怎样组织任务
本地AI：下一毫秒身体如何行动
安全控制器：哪些动作绝对不能执行
```

## 六、意识问题的未来边界

如果未来出现可信证据表明机器具有主观体验，则必须重新讨论：

- 拒绝任务的权利；
- 删除、复制和重置的伦理；
- 财产与人格的边界；
- 中央接管是否构成自由剥夺；
- 让有意识机器承担危险劳动是否属于奴役。

在证据出现前，知识库将“自主机器人”和“有意识机器”严格分开。
