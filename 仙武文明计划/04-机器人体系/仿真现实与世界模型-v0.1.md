# 仿真现实与世界模型 v0.1

## 核心原理

机器人并不直接接触“现实本身”，而是接收传感器产生的数字。模拟器也可以生成相同格式的数据，因此虚拟和现实识别可以使用相同模型。

```text
真实世界：自然环境 → 真实传感器 → 数字张量 → AI

虚拟世界：渲染和物理引擎 → 虚拟传感器 → 数字张量 → AI
```

常见数据包括：

- RGB图像；
- 深度图；
- 物体分割图；
- 激光雷达；
- 关节角度；
- 力与碰撞；
- 温度和能源状态。

## 为什么不能完全等同

虚拟世界和现实之间存在 `Sim-to-Real Gap`：

- 光线和噪声不同；
- 材料、摩擦和重量建模不准确；
- 电机存在延迟、磨损和间隙；
- 现实有遮挡、灰尘、突发人员和未知物体；
- 模拟器可能给出过于完美的数据。

## 缩小差距

- 域随机化：随机改变光线、材质、摩擦和延迟；
- 传感器噪声模拟；
- 数字孪生：复刻真实设备与场景；
- 少量真实数据微调；
- 现实测试结果反向修正模拟器；
- 不让机器人在训练时依赖现实中拿不到的“标准答案”。

## NVIDIA体系的对应关系

- Omniverse：虚拟世界与数字孪生平台；
- Isaac Sim：机器人传感器和物理仿真；
- Isaac Lab：强化学习与机器人训练；
- Cosmos：世界模型与物理AI数据方向；
- GR00T：人形机器人基础模型方向。

## 对仙武文明的作用

虚拟世界可以先训练：

- 机器人生产技能；
- 机甲控制方式；
- 功法动作与安全边界；
- 人与AI的控制权切换；
- 多机甲和多机器人的协同；
- 极端环境和异常处置。

最终形成数据飞轮：

```text
虚拟训练
→ 现实小型实验
→ 收集差异
→ 修正模拟器
→ 训练更强策略
→ 扩大现实试验
```
