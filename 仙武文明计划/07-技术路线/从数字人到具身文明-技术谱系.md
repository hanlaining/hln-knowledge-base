# 从数字人到具身文明的技术谱系

## 一、灵感起点

本计划本轮灵感从数字人的口型问题开始：数字人说话时，嘴巴如何知道什么时候张开？

答案揭示了现代AI系统的模块化本质：

```text
语言模型决定说什么
语音模型决定怎样发声
口型模型决定嘴如何运动
表情模型决定脸如何变化
姿态模型决定身体怎样行动
控制系统把多个组件统一起来
```

每个神经网络模型都像一个器官或能力。多个模型、数据库、权限和调度程序组成数字人智能体；再接入机械身体，就形成实体机器人。

## 二、神经网络模型不是只有LLM

神经网络是大类，LLM只是处理语言的一种：

```text
神经网络模型
├─ LLM：理解和生成语言
├─ ASR：声音转文字
├─ TTS：文字转声音
├─ 声音转换：改变音色
├─ 口型模型：声音驱动嘴部
├─ 视觉模型：识别人、物体和环境
├─ 姿态模型：识别身体骨骼与动作
├─ 世界模型：预测环境和动作后果
└─ 控制模型：计算机器人和机甲动作
```

## 三、口型映射与数据库

传统3D数字人可能使用小型映射表：

```text
音素 b/p/m → 双唇闭合
音素 a → 张嘴
音素 u/o → 圆嘴
```

映射通常保存在代码、JSON或动画配置中；算法负责时间、强度、平滑和相邻发音影响。AI口型模型则把规律保存在模型权重中。

向量数据库通常用于知识检索和记忆，不负责嘴型：

```text
向量数据库：数字人应该回答什么
口型模型：数字人的嘴应该怎么动
```

## 四、从数字人到机器人

| 人的能力 | 数字人/机器人组件 |
| --- | --- |
| 耳朵 | 语音识别 |
| 眼睛 | 摄像头和视觉模型 |
| 大脑 | 语言、规划和世界模型 |
| 记忆 | 数据库、向量库和长期状态 |
| 声带 | 语音合成 |
| 嘴和表情 | 口型与表情模型 |
| 骨骼肌肉 | 姿态、控制模型和执行器 |
| 神经系统 | 调度、状态和权限系统 |

```text
单独模型 = 一个器官
多个模型和控制系统 = 软件智能体
智能体 + 虚拟身体 = 数字人
智能体 + 机械身体 = 机器人
人 + 智能体 + 外附机械身体 = 仙武机甲
```

## 五、虚拟世界和现实世界

机器人在两种世界中接收的都是数字：

```text
现实：摄像头和传感器产生数据
虚拟：渲染器和物理引擎产生同格式数据
```

同一个模型原则上可以处理两者。困难在于模拟和现实差距，因此需要域随机化、传感器噪声、数字孪生和现实反馈。

## 六、从NVIDIA物理AI到仙武机甲

NVIDIA Omniverse、Isaac Sim、Isaac Lab、Cosmos和GR00T体现了：

- 在虚拟世界构造可计算环境；
- 让机器人观察、行动并学习；
- 将训练能力迁移到现实；
- 用世界模型预测物理后果；
- 让人形机器人学习通用任务。

仙武文明在此基础上增加：

- 人类意图接口；
- 共享自主；
- 第二身体体验；
- 功法作为具身技能资产；
- 文明级权限与收益机制。

## 七、技术演化链

```text
数字人口型与表情
→ 完整虚拟角色
→ 动作捕捉和身体驱动
→ 虚拟机器人和世界模型
→ 自主实体机器人
→ 安全外附式人体增强
→ 人机共享自主机甲
→ 多域个人文明载具
```

每一步都能独立产生价值，避免只有完成最终科幻机甲才算成功。
