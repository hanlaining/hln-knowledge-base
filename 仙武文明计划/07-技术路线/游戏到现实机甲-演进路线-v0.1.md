# 游戏到现实机甲演进路线 v0.1

## 核心判断

游戏不是最终机甲的宣传品，而是未来人机控制、功法生态和文明机制的第一实验场。

专业上对应：

- 人在环仿真；
- 具身数据飞轮；
- 行为遥测；
- 神经肌肉接口沙盒；
- 仿真到现实管线；
- 数字孪生。

## 阶段一：普通输入的虚拟机甲

先使用键鼠、手柄和摄像头建立：

- 随动、共享、功法和自动模式；
- 机甲身体状态；
- 能源、热量和损伤模型；
- 功法创建、组合和认证；
- 控制权切换的用户体验。

目标是验证机制和体验，不追求昂贵硬件。

## 阶段二：人体外部信号

逐步加入：

- IMU；
- 压力和足底传感；
- 眼动；
- 表面肌电；
- 简单触觉反馈。

观察哪些信号真正提高意图识别，哪些只增加复杂度。

## 阶段三：低风险实体设备

- 康复辅助；
- 坐姿或固定式机械臂；
- 低速外骨骼；
- 工业辅助工具；
- 有限力量和明确急停。

不直接跳到高速、高功率或战斗设备。

## 阶段四：工业与救援

在高度限定场景验证：

- 长时间稳定性；
- 载荷和能源；
- 人机交接；
- 自动返航；
- 故障隔离；
- 多机器人协同。

## 阶段五：高机动贴身机甲

在材料、动力和安全成熟后，研究真正的第二身体体验、复杂功法和多环境适应。

## 数据飞轮

```text
玩家操作
→ 产生意图和动作数据
→ 训练共享自主AI
→ 仿真异常和极端场景
→ 低风险硬件验证
→ 现实差异回流模拟器
→ 改进功法与控制
```

## 数据和伦理

- 用户知道收集了什么；
- 生理和动作数据属于敏感数据；
- 用户可退出、删除和导出；
- 不把娱乐数据未经允许用于高风险领域；
- 功法创作者和动作贡献者拥有权益；
- 游戏机制不能诱导用户接受现实中不合理的AI接管。
