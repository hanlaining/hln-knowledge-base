# 术语表

| 术语 | 英文/专业表达 | 本计划中的含义 |
| --- | --- | --- |
| 仙武文明 | Xianwu Civilization | AI、机器人、机甲、功法与人类机制共融的文明形态 |
| 文明认知网 | Civilization Cognitive Mesh | 连接主权AI、行业AI、个人AI和物理设备的新型网络 |
| 中央大脑 | Civilization AI Brain | 某一主权域或组织域的AI控制平面，不指全球只有一个模型 |
| 分层多智能体 | Hierarchical Multi-Agent System | 主AI将任务分派给不同专业智能体并协调结果 |
| 主权AI | Sovereign AI | 受国家、组织或共同体治理的数据、模型与智能基础设施 |
| 机制设计 | Mechanism Design | 设计权力、收益、激励、权限、反馈和纠错规则 |
| 赛博物理系统 | Cyber-Physical System | 软件、网络和现实机器共同形成的闭环系统 |
| 具身智能 | Embodied Intelligence | AI通过身体感知并作用于现实或模拟环境 |
| 人在环 | Human-in-the-Loop | 人持续参与系统判断、监督或控制 |
| 共享自主 | Shared Autonomy | 人负责意图和目标，AI负责动作补全与安全控制 |
| 意图感知 | Intention Recognition | 通过肌电、姿态、压力、视线等外部信号判断人的动作意图 |
| 扩展身体图式 | Extended Body Schema | 人将外附机甲逐渐感知为自身身体的延伸 |
| 功法 | Composable Embodied Skill Policy | 可组合、可训练、可认证的具身技能策略包 |
| 机器自我模型 | Machine Self-Model | 机器人理解自身结构、能力、状态、损伤和权限的内部模型 |
| 受限自主 | Bounded Autonomy | 机器人可自主完成任务，但不能越过根本权限和安全边界 |
| 世界模型 | World Model | 预测环境状态、动作后果和物理变化的模型 |
| 数字孪生 | Digital Twin | 与现实设备或环境对应的可计算虚拟模型 |
| 仿真到现实 | Sim-to-Real | 将模拟环境中学习或验证的能力迁移到真实设备 |
| 自动化红利 | Automation Dividend | 自动化新增生产力向社会成员分配的收益 |
| 公正转型 | Just Transition | 让旧产业人员有保障地转入新产业的制度安排 |
| 多域机甲 | Multi-Domain Mecha | 设想中能够适应陆地、飞行、水下或太空等多种环境的机甲 |
| 关键待发现技术 | Technology Gap | 当前科学或工程尚不能满足、需要未来突破的条件 |
