# 仙武纪元命名规范 v0.1

## 一、命名目标

仙武文明的名称应同时具有：

- 东方古典意象；
- 未来科技感；
- 清晰的系统层级；
- 可扩展的版本与型号规则；
- 中文文化名称和专业技术名称的双重表达。

名称不能只是把“天、神、玄、灵”随机堆叠。一个好名称应当能够暗示功能、层级或运行方式。

## 二、双名称原则

每个重要系统同时保留：

```text
文化名称：用于世界观、公众品牌和文明记忆
专业名称：用于研究、工程、法律和跨国协作
```

例如：

```text
玄磁天幕
Visible Magneto-Active Defense System
```

文化名承载想象，专业名避免工程含义模糊。

## 五、版本和型号组合

工程档案继续使用稳定编号，文化名称作为代号：

```text
CAB-v0.1「天枢初鸣」
MAP-v0.1「灵台试铸」
XW-A01「青锋」
XW-H01「玄岳」
GF-X01「流云步」
```

编号负责精确，代号负责记忆与文明气质。

## 六、命名检查清单

- 名称是否能暗示真实功能？
- 是否与已有系统重名或层级冲突？
- 是否只有玄幻感而没有技术含义？
- 专业名称能否让外部工程师理解？
- 后续版本和子型号是否容易扩展？
- 是否把尚未实现的能力夸大成已经存在？
- 是否符合“古风＋未来纪元”，而不是简单复古？
