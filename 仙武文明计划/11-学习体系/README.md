# 仙武文明计划学习体系

## 学习目标

仙武文明不是单一专业项目。学习目标不是让一个人成为所有领域的博士，而是培养：

> 能确定文明方向、拆分复杂系统、识别专业边界、连接不同专家并判断整体机制是否成立的总架构能力。

## 学习深度分级

| 等级 | 定义 | 你应达到什么程度 |
| --- | --- | --- |
| A｜架构必修 | 直接影响整体判断和系统拆分 | 能独立解释、建模、提出方案并识别明显错误 |
| B｜接口精通 | 与主攻专家高频协作的相邻领域 | 能读专业材料、问到关键点、理解约束和接口 |
| C｜领域主攻 | 需要多年实验和工程经验 | 由对应怪才深耕，你掌握地图、评价标准和重大风险 |
| D｜前沿观察 | 当前仍属研究或待发现技术 | 跟踪证据，不把畅想写成已实现事实 |

## 总体学习原则

```text
先获得全局地图
→ 选择一个当前主轴
→ 用项目暴露真实知识缺口
→ 学习缺口对应理论
→ 做最小实验
→ 把结果写回知识库
→ 与领域盟友交叉审查
```

不要按照学校课程顺序把全部学科从头学完以后才开始。这个计划规模过大，最有效的方式是“地图先行、项目牵引、理论补强、循环迭代”。

## 当前建议主轴

第一主轴建议从**软件与虚拟世界**开始：

```text
Python/TypeScript
→ AI智能体
→ 多智能体调度
→ 游戏/仿真中的虚拟机甲
→ 功法数据结构
→ 共享自主控制实验
```

原因是成本低、反馈快、风险可控，并且能够同时为天枢灵网、万法天市、演武天鉴和虚拟机甲提供第一批可验证原型。
