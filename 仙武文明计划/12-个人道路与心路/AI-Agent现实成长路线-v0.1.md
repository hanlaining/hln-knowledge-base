# AI-Agent现实成长路线 v0.1

## 路线目标

用AI Agent领域建立三样东西：

1. 市场愿意持续付费的专业能力；
2. 不完全依赖出售个人时间的可复用资产；
3. 未来进入天枢灵网、机器人和机甲研究的技术底座。

## 第一层：工程基础

需要掌握：

- Python和TypeScript；
- Git、测试和基本软件工程；
- HTTP、API、后端和数据库；
- Linux/Windows环境和部署；
- 基本数据结构、异步任务和状态管理。

交付证据：独立完成一个可部署、可测试、有日志的应用。

## 第二层：LLM应用

- 模型调用和上下文；
- 结构化输出；
- 工具调用；
- RAG和知识库；
- 提示注入和数据安全；
- 成本、速度和质量取舍；
- 评测而不是只凭感觉。

交付证据：一个能够稳定解决真实业务问题的AI应用。

## 第三层：Agent系统

- 任务规划；
- 工作流和状态机；
- 短期与长期记忆；
- MCP/API工具生态；
- 多智能体协作；
- 权限和资源预算；
- 人工审批；
- 中断、恢复和幂等；
- 可观测性和事故复盘。

交付证据：一个能够连续执行复杂任务、失败后恢复并接受审计的Agent系统。

## 第四层：产品与商业

- 找到高频、昂贵、可量化的问题；
- 与真实用户验证；
- 把定制项目抽象成可复用产品；
- 设计交付边界、定价和维护；
- 积累案例、作品和可信声誉；
- 建立合作和销售渠道；
- 避免只做没有用户的技术演示。

交付证据：有人愿意使用、续费或为结果付费。

## 第五层：可复用资产

- Agent框架和组件；
- 行业知识库；
- 评测数据集；
- 工作流模板；
- 插件和工具市场；
- 教程、文档和个人品牌；
- 产品收入与长期合作关系。

目标是让一次学习和一次交付能够在未来重复产生价值。

## 第六层：连接仙武文明

| Agent现实能力 | 仙武文明用途 |
| --- | --- |
| 多智能体调度 | 天枢灵网 |
| 权限和工具调用 | 文明分层控制 |
| RAG和知识系统 | 分布式文明知识 |
| 状态、恢复和审计 | 机器人与机甲安全 |
| 数据飞轮和评测 | 演武天鉴 |
| 插件市场 | 万法天市 |
| 用户工作流 | 功法和人机协作 |

## 当前优先级

```text
P0：职业和现金流可持续
P1：形成Agent工程深度和作品
P2：沉淀可复用产品与知识产权
P3：建立怪才盟友网络
P4：逐步投入虚拟机甲和长期文明原型
```

## 防止路线跑偏

- 每学习一个概念，都要对应一个可运行成果；
- 每做一个项目，都要沉淀成组件、文档或案例；
- 每追一个新模型，都问它是否改善真实结果；
- 每个季度重新检查收入、能力、健康和长期愿景是否平衡；
- 不用财富自由的幻想替代具体现金流和资产指标；
- 不为了短期收入永久放弃长期技术积累。
