# 个人道路与心路

## 目录目的

这个目录不负责描述整个仙武文明“应该是什么”，而负责记录创始人本人为什么形成这些思想、现实处境如何影响选择，以及不同阶段的主攻方向怎样变化。

它回答三个问题：

```text
我现在为什么做这件事？
我当前必须先解决什么现实问题？
我的长期文明判断发生了怎样的演进？
```

## 记录规则

- 重要思想保留原话；
- 每次记录精确到日期、时间和时区；
- 不用今天的成熟观点覆盖过去的不成熟想法；
- 观点改变时记录“为什么改变”，而不是删除旧版本；
- 区分个人愿望、现实计划、文明判断和已验证结果；
- 现实阶段优先保证生存、健康、现金流和可持续成长。
