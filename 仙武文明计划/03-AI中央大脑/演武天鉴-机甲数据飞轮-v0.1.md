# 演武天鉴：机甲数据飞轮 v0.1

## 一、定义

“演武天鉴”是机甲时代的基础经验系统：每台机甲将在合法授权和数据分级条件下，上传训练、竞技、任务和战斗中的基础数据，使中央大脑能够持续优化机甲控制、功法和安全策略。

专业名称：

> Mecha Experience Data Flywheel

## 二、数据飞轮

```text
机甲产生基础经验数据
→ 本地清洗、脱敏和风险检查
→ 上传所属天枢节点
→ 识别成功模式、失败模式和新风险
→ 在仿真世界训练候选模型
→ 红队和独立节点验证
→ 小范围灰度部署
→ 观察现实结果
→ 安全扩大或立即回滚
```

这使每一次训练和任务都有机会成为整个体系的公共经验，但不意味着所有原始隐私和敏感数据无条件集中。

## 三、基础数据范围

候选数据包括：

- 机甲型号和软件版本；
- 功法编号和版本；
- 动作轨迹与完成结果；
- 能源、温度、负荷和损伤；
- AI辅助和人工接管时点；
- 环境类别和风险标签；
- 失误、异常和安全中止；
- 仿真与现实表现差异；
- 用户对控制自然度的评价。

默认不应直接上传：

- 可识别个人身份的原始生理数据；
- 未经授权的面部、声音和环境画面；
- 国家或组织任务的敏感坐标与目标；
- 能被直接用于越权复制高风险能力的完整原始记录。

## 四、中央学习与本地学习

不是所有数据都必须离开机甲：

```text
本地器灵核：学习个人动作习惯和身体适配

地区/流派节点：学习特定环境和功法风格

国家天枢：学习大规模安全、产业和高权限策略

公共天鉴：共享经过脱敏和验证的基础规律
```

可以通过联邦学习、模型差分、统计摘要和可信执行环境减少原始数据集中。

## 五、防止“搞事情”污染中央大脑

主要风险：

- 伪造战斗结果；
- 数据投毒；
- 大量重复数据操纵模型；
- 恶意功法诱导系统学习危险行为；
- 被攻破机甲上传虚假传感器记录；
- 利用模型更新窃取敏感知识；
- 多个账号串谋改变排行和商业价值。

基础防线：

1. 机甲硬件和软件签名证明；
2. 数据来源、时间和版本可追溯；
3. 单一用户或流派的数据不能直接改变基础模型；
4. 异常样本隔离并交叉对照其他来源；
5. 高风险模型必须在仿真中对抗测试；
6. 新模型先在低权限、小范围环境运行；
7. 保留上一稳定版本和一键回滚；
8. 重要更新由独立模型、人类专家和治理节点共同批准；
9. 把安全失败数据视为高价值信号，不因商业宣传而隐藏。

## 六、数据权益

上传经验不应只是用户对平台的无偿贡献。候选机制包括：

- 基础公共安全数据强制但严格最小化；
- 个性化和商业数据由用户选择授权；
- 对有效训练数据提供积分、分红或功法收益；
- 用户能够查看自身数据被用于哪些模型；
- 可撤回未来使用授权，但已形成的公共安全统计需按规则处理；
- 创作者功法产生的数据应关联作者权益。

## 七、自动迭代的边界

中央大脑可以自动生成、训练和测试候选版本，但不能无审查地把新策略下发全部机甲。

```text
自动学习 ≠ 自动获得现实高风险权限
```

越靠近现实身体、公共空间和高能设备，发布门槛越高。
