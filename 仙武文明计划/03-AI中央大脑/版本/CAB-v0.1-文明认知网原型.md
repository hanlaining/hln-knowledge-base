# CAB-v0.1「文明认知网原型」

## 版本目标

把中央大脑从一句概念拆成可以逐步验证的最小逻辑架构。此版本只做知识库和软件仿真，不控制现实关键设施。

## 能力范围

- 接收一个长期目标；
- 将目标拆成任务树；
- 为任务分配不同专业AI角色；
- 给每个角色配置不同知识和工具权限；
- 汇总结果、冲突和证据；
- 形成供人审查的执行计划；
- 保存不可省略的决策记录。

## 明确不做

- 不自动控制真实机器人、工厂或基础设施；
- 不拥有不可撤销权限；
- 不宣称掌握世界全部知识；
- 不模拟机器主观意识；
- 不处理国家真实机密；
- 不允许智能体自行扩大权限。

## 最小模块

```text
目标入口
→ 任务规划器
→ 智能体注册表
→ 权限与知识路由
→ 结果和证据合并器
→ 风险审查器
→ 人类批准界面
→ 审计记录
```

## 验证问题

1. 任务分解是否完整且没有重复；
2. 专业AI是否只看到必要知识；
3. 不同智能体意见冲突时能否保留而非抹平；
4. 最终建议能否追溯到来源和过程；
5. 人类能否拒绝、修改或撤销；
6. 系统失败后能否恢复到确定状态。

## 下一版本候选

`CAB-v0.2`：加入虚拟机器人和虚拟机甲任务调度，但仍不连接现实硬件。
