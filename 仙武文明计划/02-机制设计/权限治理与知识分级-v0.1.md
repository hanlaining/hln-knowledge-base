# 权限治理与知识分级 v0.1

## 基本观点

文明认知网不应让所有节点看到全部知识或调用全部能力。国家、行业、组织、个人和机器人应按职责、风险和场景获得不同权限。

但知识分级不能变成无限权力黑箱。当前原则是：

> 内容可以依法分级保密，权限依据、监督程序、责任主体和解密条件必须受到审查。

## 专业机制

- 零信任架构（Zero Trust Architecture）；
- 基于属性的访问控制（ABAC）；
- 基于能力凭证的安全（Capability-Based Security）；
- 信息分舱（Information Compartmentalization）；
- 知悉必要原则（Need-to-Know）；
- 机密计算（Confidential Computing）；
- 联邦学习（Federated Learning）；
- 不可篡改审计日志（Immutable Audit Log）；
- 策略执行点（Policy Enforcement Point）；
- 解密和公开机制（Declassification Mechanism）。

## 权限不是简单等级

不采用纯粹的“高等级可以看一切”。权限应由多个属性共同决定：

```text
主体身份
+ 当前职责
+ 任务目的
+ 所在区域
+ 数据敏感度
+ 时间范围
+ 风险等级
+ 多方授权
→ 临时能力凭证
```

## 知识与能力分离

知道某项技术，不等于拥有执行它的能力：

```text
知识访问权
≠
模型调用权
≠
设备控制权
≠
不可逆行动授权
```

例如某人可以学习机甲动力原理，但不能因此获得控制国家级重型机甲的权限。

## 机器人权限

机器人接收的不是“中央AI可以随时做一切”，而是限定能力：

- 指定任务；
- 指定场所；
- 指定时限；
- 指定资源上限；
- 指定禁止行为；
- 指定失联策略；
- 指定人工接管条件。

## 防止系统性风险

- 重要节点避免使用完全相同的模型和策略；
- 高风险决策需要多个相互独立的验证者；
- 中央AI不能绕过本地硬件安全控制器；
- 权限升级必须留下可审计证据；
- 异常策略先在数字孪生和隔离区测试；
- 关键系统具备离线降级模式。
