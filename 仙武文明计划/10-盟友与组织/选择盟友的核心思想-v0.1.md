# 选择盟友的核心思想 v0.1

## 一、创始原文

> 我想要的是一群怪人 在各自领域主攻深耕 并且在其他领域也精通的 怪人 ，天才不过是虚名我的团队不需要拔苗助长的天才 需要一群怪才期待和他们碰撞的头脑风暴

以上原文作为本计划选择盟友的思想原点，永久保留，不因后续专业化整理而删除或覆盖。

## 二、这里的“怪人”是什么

这里的怪，不是为了与众不同而故意反常，也不是把难以合作、傲慢或破坏规则包装成个性。

它指的是一类**不被单一学科、履历和标准答案限制的人**：

- 在一个主攻领域拥有真正深入的长期积累；
- 能理解多个相邻乃至遥远领域的基本语言；
- 敢于质疑默认前提，但愿意接受证据纠正；
- 能把别人认为无关的知识连接成新结构；
- 不满足于发表观点，能够把想法变成原型、实验和机制；
- 拥有独立判断，又不把独立误解为拒绝协作；
- 面对未知时保持兴奋，也能诚实地说“现在不知道”。

专业上可称为：

- **Polymathic Specialist**：博学型专家；
- **T-shaped / π-shaped Professional**：T型或π型人才；
- **Transdisciplinary Thinker**：超学科思考者；
- **Systems Thinker**：系统思维者；
- **Boundary Spanner**：跨领域边界连接者；
- **Creative Nonconformist**：创造型非从众者。

但这些术语只是描述，不是新的头衔。团队不为标签招人，只为真实能力与共同创造招人。

## 三、为什么不迷信“天才”

“天才”经常是外界对结果的事后命名，也可能变成一种过早施加在人身上的身份压力。

本计划不需要拔苗助长的天才，意味着：

- 不以年龄、学历、竞赛、名校或社会名气代替真实能力；
- 不要求成员为了证明天赋而隐藏失败和困惑；
- 不把快速回答当作深度思考；
- 不把个人英雄神话置于团队系统之上；
- 不把一个领域的成功自动推导成所有领域的正确；
- 不用“你是天才”迫使年轻成员透支成长。

团队真正重视的是：

```text
长期深耕
+ 跨域理解
+ 原创连接
+ 实际创造
+ 认知诚实
+ 协作碰撞
+ 对文明目标的责任感
```

怪才不是“比天才更响亮的称号”，而是一种持续创造、持续学习和持续突破边界的工作状态。

## 四、理想盟友的能力结构

### 1. 一根足够深的主轴

每位核心盟友必须至少有一个能够承担重大责任的主攻领域，例如：

- AI与多智能体；
- 机器人与控制；
- 材料与能源；
- 机械和机甲结构；
- 人体科学与人机交互；
- 虚拟世界和仿真；
- 经济、法律与机制设计；
- 社会学、心理学与文明研究；
- 艺术、叙事和东方审美；
- 制造、供应链和产业落地。

所谓深耕，不只是知道概念，而是能够：

- 判断真正难点；
- 识别伪问题和虚假承诺；
- 设计实验；
- 解释失败；
- 对结果负责；
- 教会其他领域成员必要知识。

### 2. 多条可以连接他人的横轴

“其他领域也精通”不要求每个人成为所有领域的最高专家，而是要求拥有足够的跨域理解能力：

- 能听懂其他专业的关键约束；
- 能识别自己提出的方案会给其他系统带来什么代价；
- 能使用共同语言讨论接口；
- 能主动补齐知识，而不是把问题永远推给别人；
- 能在两个领域之间创造此前不存在的连接。

### 3. 统一复杂系统的能力

仙武文明真正稀缺的不是更多孤立专家，而是能让多个专家成为一个系统的人。

这种能力称为：

> Integrative Complexity，整合复杂性。

表现包括：

- 同时容纳相互冲突的观点；
- 不急于用简单口号消灭矛盾；
- 找到不同专业之间真正的接口；
- 把宏大目标拆成可验证的小闭环；
- 在局部最优和整体最优之间作出判断；
- 明白技术、架构和机制必须同时成立。

## 五、选择盟友的核心标准

| 维度 | 要观察什么 | 不被什么迷惑 |
| --- | --- | --- |
| 专业深度 | 是否真正解决过本领域难题 | 头衔、术语数量 |
| 跨域能力 | 能否快速进入其他领域并准确交流 | 泛泛而谈的“什么都懂” |
| 原创性 | 能否发现新问题和新连接 | 只会复述热门观点 |
| 落地能力 | 能否做实验、原型和复盘 | 只擅长宏大表达 |
| 认知诚实 | 是否区分事实、推论和幻想 | 永远显得自己正确 |
| 建设性异议 | 是否敢反对，同时给出更好方案 | 为反对而反对 |
| 协作能力 | 是否能让他人变得更强 | 个人英雄主义 |
| 责任边界 | 是否理解力量、权限和后果 | 只追求“能做出来” |
| 长期主义 | 是否能忍受漫长、重复和失败 | 短期热情与追逐风口 |
| 文明共识 | 是否认同技术最终服务于人 | 单纯崇拜力量和控制 |

## 六、不选择什么样的人

以下特征即使伴随很强的个人能力，也不适合作为核心盟友：

- 迷恋头衔、等级和天才身份；
- 把信息差当作个人权力，不愿共享关键知识；
- 只会指出问题，从不承担解决责任；
- 为证明自己聪明而故意让系统复杂；
- 把跨领域理解误解成轻视专业深度；
- 无法承认错误，失败后只寻找替罪者；
- 把他人的想法据为己有；
- 对普通人缺少尊重，只想控制而不想普惠；
- 认为宏大目标可以自动豁免安全、伦理和责任；
- 在公开场合赞同愿景，实际行动只追求个人利益。

“怪”不能成为伤害团队的许可证。真正的怪才可以不合常规，但必须可信、负责，并能与其他怪才共同工作。

## 七、盟友不是员工名单

仙武文明不可能由一个人完成，也不能只靠传统上下级组织。

“盟友”意味着：

- 对共同目标拥有真实理解；
- 在自己的领域拥有独立判断权；
- 可以公开提出反对意见；
- 对创造结果拥有署名和合理权益；
- 能够离开个人中心仍继续推进共同目标；
- 既接受系统机制，也参与机制演进。

团队的核心关系不是盲目服从，而是：

> 共同方向下的高信任、强碰撞、清边界与真负责。

## 八、建议的组织角色

### 文明总架构者

维护长期愿景和不同系统之间的一致性，不替代各领域专家作出全部专业判断。

### 领域主攻者

在AI、机器人、材料、机制等核心领域承担深度和最终质量责任。

### 接口型盟友

精通两个或更多领域，负责发现术语、数据、目标和约束之间的不一致。

### 原型创造者

把抽象思想快速变成仿真、游戏、实验装置或可以被检验的最小闭环。

### 红队与反对者

专门寻找失败路径、权力滥用、错误假设和被忽视的人群；其任务不是拖慢，而是避免整个文明高速走错方向。

### 机制与守界者

关注收益、权限、安全、责任和社会转型，确保力量增长与治理能力同步。

一个人可以同时承担多个角色，但不能因为是创始人、明星专家或核心成员而免于质疑。

## 九、怎样真正选择盟友

传统简历和一次面试不足以判断怪才。更合适的方法是共同完成一个小型真实问题。

### 第一步：开放问题

给出一个没有标准答案、需要多个领域共同思考的问题，观察候选者首先提出什么问题，而不是只看最终答案。

### 第二步：个人深挖

让候选者解释自己真正深耕的领域、失败案例和目前仍不懂的部分。

### 第三步：跨域翻译

让其把专业问题讲给其他领域成员，并理解其他人的约束。

### 第四步：小型共同原型

用数天或数周做出一个可以被测试的成果，观察执行、复盘、归功和冲突处理。

### 第五步：逆向辩论

要求候选者先反驳自己的方案，再为自己原本不赞同的方案找出最强理由。

### 第六步：长期观察

真正的盟友关系通过共同经历困难形成，不通过一次精彩演讲决定。

## 十、头脑风暴的碰撞机制

期待碰撞，不等于无规则争论。建议采用：

```text
先定义共同问题
→ 分别独立提出方案，避免过早从众
→ 交换不同领域的关键约束
→ 强制提出最强反方观点
→ 标出事实、推论、假设和幻想
→ 寻找能够兼容多个观点的新结构
→ 选出最小可验证实验
→ 用结果而不是身份决定下一步
```

头脑风暴应保护：

- 不成熟但有潜力的想法；
- 对核心前提的挑战；
- 少数意见；
- 说“不知道”的权利；
- 思考较慢但更深入的人；
- 对创意来源的准确署名。

头脑风暴不保护：

- 人身攻击；
- 通过音量和地位压制他人；
- 用术语制造虚假权威；
- 重复争论但拒绝实验；
- 偷换目标；
- 会后抢占他人成果。

## 十一、权限应随信任和责任成长

加入愿景不等于立即获得全部知识和系统权限。盟友关系可以分阶段：

```text
观察者
→ 共同研究者
→ 项目盟友
→ 领域负责人
→ 核心架构盟友
```

权限增长依据：

- 持续贡献；
- 认知诚实；
- 承担责任；
- 正确处理敏感信息；
- 面对冲突时维护共同目标；
- 能培养并成就其他成员。

这不是僵化官僚等级，而是让能力、信任、责任和权限保持一致。

## 十二、团队文化的底线

1. 可以挑战任何观点，包括创始人的观点；
2. 不可以用挑战观点为借口贬低人格；
3. 专业结论以证据和实验为准，不以身份为准；
4. 文明方向由共同机制维护，不被单一专家绑架；
5. 创造必须准确署名，收益必须与真实贡献相匹配；
6. 团队允许古怪、浪漫和疯狂设想，但工程记录必须诚实；
7. 不培养依赖崇拜的追随者，而培养可以独立开创新领域的盟友；
8. 最好的盟友不是永远赞同，而是能在关键时刻阻止彼此犯下巨大错误。

## 十三、一句话原则

> 不寻找被“天才”称号塑造的人，而寻找在一个领域扎得足够深、又能跨过学科边界与他人共同创造的怪才；他们彼此碰撞，不是为了证明谁更聪明，而是为了产生任何单独头脑都无法独自抵达的新世界。

## 十四、仍需继续讨论的问题

- 核心盟友是否共享知识库、模型、专利或组织所有权？
- 如何计算跨领域贡献，避免只奖励最容易被看见的人？
- 如何处理极强创造力与长期协作能力之间的冲突？
- 如何保护年轻怪才成长，而不再次制造“天才”压力？
- 如何让核心团队保持认知多样性，而不是逐渐形成新的同温层？
- 当文明方向与短期商业收益冲突时，由什么机制裁决？
