# 功法体系与技能市场 v0.1

## 一、功法的专业定义

仙武文明中的功法不是单纯动作动画，而是：

> 可组合、可训练、可验证、可认证并可跨机甲适配的具身技能策略包。  
> Composable Embodied Skill Policy

## 二、一个功法包含什么

```text
功法元数据
├─ 名称、作者、版本、许可证
├─ 适配机甲和人体条件
├─ 风险和权限等级
└─ 训练与验证记录

执行策略
├─ 动作轨迹
├─ 重心与步法
├─ 力量和速度分配
├─ 能源和热量预算
├─ 环境触发条件
├─ 防守与中止动作
└─ AI决策策略

安全约束
├─ 关节和人体极限
├─ 禁止目标和场所
├─ 失控与误触发处理
├─ 硬件安全控制规则
└─ 人类接管条件
```

## 三、自创功法

用户可以通过以下方式创造：

- 自己完成动作示范；
- 在虚拟世界编辑轨迹和规则；
- 将多个基础功法组合；
- 让AI根据目标生成候选动作；
- 通过多次训练形成个人风格；
- 将机器人或机甲的经验提炼成新技能。

但自创不等于直接运行：

```text
创作
→ 静态安全检查
→ 数字孪生仿真
→ 对抗与异常测试
→ 限速虚拟试用
→ 适配认证
→ 按风险开放现实使用
```

## 四、功法商业模式

- 免费公共基础功法；
- 作者付费功法；
- 学校、流派和组织功法；
- 企业工业技能包；
- 订阅式训练课程；
- 竞技赛事和排名；
- 功法定制与个体适配；
- 功法组合授权；
- 使用次数或生产收益分成。

创作者权益应包括：

- 署名；
- 版本所有权；
- 收益分成；
- 使用范围控制；
- 被模型学习时的授权与补偿；
- 对危险改造版本的区分权。

## 五、功法流派

流派不是简单皮肤，而是对控制哲学的不同选择：

- 高力量、低动作数量；
- 高机动和连续重心转换；
- 顺应性防御和力量重定向；
- 多机协同；
- 工业精密操作；
- 救援和生命保护；
- 能源效率优先；
- 人类手动占比高或AI自动占比高。

## 六、功法与机甲适配

同一功法不能直接在所有机甲和所有人身上执行。运行前需要转换：

```text
抽象功法意图
→ 读取操作者身体和机甲能力
→ 重新计算关节轨迹与力量
→ 检查环境和安全限制
→ 生成当前设备可执行版本
```

这类似软件的跨平台编译，但对象是身体与机械动作。

## 七、功法生态的文明意义

功法将人的身体经验、AI策略和机器能力变成可传承的文明资产。未来的教育不只是学习文字知识，也可能包括学习如何与第二身体协作，以及如何创造新的具身能力。
