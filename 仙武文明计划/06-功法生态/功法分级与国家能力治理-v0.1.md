# 功法分级与国家能力治理 v0.1

## 一、治理对象是能力，不只是文件

危险能力不能只通过隐藏文档或软件加密管理，因为相同效果可能由不同功法组合产生。治理需要同时检查：

- 功法本身；
- 机甲硬件上限；
- 能源和工具；
- 运行场所；
- 操作者资格；
- 组合后的实际效果。

## 二、初步分级

| 等级 | 能力范围 | 例子 |
| --- | --- | --- |
| GF-L0 | 康复与生活辅助 | 行走辅助、姿态矫正 |
| GF-L1 | 娱乐、运动和一般劳动 | 虚拟竞技、轻型搬运 |
| GF-L2 | 高负荷工业与救援 | 重物操作、危险区救援 |
| GF-L3 | 专业高风险能力 | 高速竞技、专业安保 |
| GF-L4 | 可造成大范围破坏 | 严格国家许可和多方控制 |
| GF-L5 | 战略级能力 | 国家级隔离、监督和专门治理 |

分级不是永久不变，应根据机甲能力、社会环境和事故证据调整。

## 三、执行条件

```text
操作者资格
+ 功法许可证
+ 机甲硬件能力
+ 场所授权
+ 当前任务
+ 实时风险状态
+ 多方批准（高等级）
→ 是否允许执行
```

## 四、国家所有不等于无限使用

高杀伤能力归国家或经法律授权的公共体系管理，可以降低个人滥用风险，但仍需要：

- 法律授权；
- 使用目的限制；
- 多方批准；
- 独立监督；
- 全程审计；
- 事故责任；
- 定期复核；
- 明确的停用与销毁机制。

## 五、技术安全

- 功法使用加密签名；
- 高风险模块不能在消费级硬件运行；
- 安全控制器独立于上层AI；
- 禁止功法自行提升权限；
- 多个低风险功法组合后必须重新评估；
- 运行过程中持续检测实际效果，而非只在启动前检查；
- 异常时进入降能、锁定或安全撤离状态。

## 六、开放创新与安全的平衡

建议采用沙盒分层：

```text
开放创作区：任何人可以在纯虚拟世界创造
认证训练区：允许有限物理反馈和标准化测试
现实民用区：只运行通过认证的低风险功法
专业作业区：持证人员和指定设备
国家能力区：严格隔离、监督和法律授权
```

这样既不扼杀自创功法，也不让虚拟创意未经验证直接变成现实危险能力。
