# 万法天市：功法审核交易平台 v0.1

## 一、定义

“万法天市”是世界级功法创作、训练、审核、交易和迭代平台。用户可以自创功法，通过官方或获得授权的认证节点审核后公开售卖。

它不是普通应用商店，而是连接：

- 创作者；
- 机甲用户；
- AI训练；
- 仿真测试；
- 现实认证；
- 赛事和流派；
- 数据收益；
- 国家与地区治理。

## 二、平台闭环

```text
用户创作功法
→ 私有虚拟沙盒训练
→ 自动安全和兼容检查
→ 天工律院审核
→ 分级认证
→ 万法天市上架
→ 用户购买、训练和评价
→ 演武天鉴收集合法基础数据
→ 创作者迭代新版本
→ 收益和贡献回流
```

## 三、审核不是判断“好不好看”

审核至少包括：

- 功法是否真的实现宣传能力；
- 是否适配声明的机甲和人体范围；
- 是否可能造成关节、能源和环境风险；
- 是否包含越权、隐藏通信或恶意逻辑；
- 多个功法组合后是否产生新的高风险能力；
- 是否抄袭他人动作、模型或策略；
- 数据采集和隐私声明是否真实；
- 实际风险等级是否与申报一致。

## 四、上架层级

| 层级 | 范围 |
| --- | --- |
| 虚境试法 | 仅虚拟世界使用，可开放大胆创造 |
| 民用认证 | 生活、运动、娱乐和低风险辅助 |
| 专业认证 | 工业、救援和持证场景 |
| 限域认证 | 只允许指定设备、地点和任务 |
| 国家能力 | 不进入公开市场，由专门体系管理 |

## 五、创作者商业权益

- 一次性购买；
- 订阅；
- 使用次数分成；
- 生产效率收益分成；
- 赛事和流派授权；
- 个体适配服务；
- 衍生功法授权；
- 有效基础数据贡献红利；
- 被官方基础功法吸收时的署名与补偿。

## 六、平台防破坏机制

针对恶意用户和“搞事情”的人：

- 功法包必须签名且来源可追溯；
- 审核环境与现实机甲隔离；
- 上架版本不能在后台悄悄替换；
- 更新需要重新进行差异审核；
- 高风险组合由运行时再次判断；
- 新功法先限量、限速、限场景发布；
- 异常行为触发冻结、回滚和证据保全；
- 审核模型本身接受独立红队测试；
- 申诉由不同于原审核方的节点处理；
- 国家能力与公开市场在数据、模型和硬件上隔离。

## 七、避免平台垄断

“一体化世界平台”应统一协议和安全标准，但允许多个受监管节点运营：

- 创作者可以跨节点迁移作品和声誉；
- 用户可以导出购买记录和个体适配数据；
- 平台不得单方面夺取功法所有权；
- 认证标准公开，敏感测试细节可以分级；
- 地区节点遵守当地法律，但保持基础互操作；
- 核心协议由多方共同治理。

## 八、文明商业意义

万法天市可能把“人的动作经验和创造力”变成新的世界级数字资产，使用户既是消费者，也是创作者、训练者、流派成员和文明能力贡献者。
