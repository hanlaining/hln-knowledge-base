# MAP-v0.1「虚拟共融原型」

## 版本目标

不制造现实高功率机甲，先在游戏或仿真中验证人体外部输入、共享自主、功法调用和控制权切换。

## 输入

- 键鼠或手柄作为基线；
- 摄像头姿态；
- IMU或手机传感器；
- 可选表面肌电实验设备；
- 语音和眼动作为补充。

## 输出

- 虚拟机甲动作；
- 控制模式状态；
- 意图置信度；
- AI辅助比例；
- 失误、接管和中止记录；
- 功法执行轨迹。

## 核心功能

1. 随动、共享和自动三种控制模式；
2. 无缝但明确的控制权切换；
3. 最少三种可组合功法；
4. 虚拟安全限制和能量预算；
5. 记录人在高负荷下的操作数据；
6. 允许用户评价AI介入是否自然。

## 不包含

- 现实高功率执行器；
- 现实武器；
- 侵入式神经接口；
- 对人体施加危险力反馈；
- 未经用户知情的数据采集。

## 退出条件

满足以下条件后才考虑MAP-v0.2：

- 用户能稳定理解当前控制权归属；
- AI辅助显著降低错误且不降低主观掌控感；
- 功法能够跨虚拟型号复用；
- 所有危险动作可被硬规则立即终止；
- 采集的数据足以描述动作意图和执行差异。
