# 外附式意图感知与人机共融 v0.1

## 当前边界

本路线不以植入大脑或直接读取思想为前提。优先从安全、可撤除、可分阶段验证的人体外部信号入手。

## 可用信号

| 信号 | 能推断什么 | 主要限制 |
| --- | --- | --- |
| 表面肌电 sEMG | 肌肉发力和提前动作趋势 | 个体差异、汗液和位置变化 |
| IMU | 姿态、角速度和加速度 | 长时间存在漂移 |
| 压力/力传感器 | 人向哪个方向施力 | 需要合理布局和校准 |
| 关节编码器 | 肢体与机甲当前角度 | 只能看到结果，难独立预测意图 |
| 足底压力 | 重心、步态、起跳和转向 | 鞋和地面条件影响 |
| 眼动 | 注意对象和目标方向 | 不等于行动命令 |
| 语音/手势 | 清晰的显式指令 | 高噪声或高负荷时受限 |
| 心率/呼吸 | 疲劳和压力状态 | 不能单独确定具体动作 |

## 融合原理

任何单一信号都不可靠，需要多模态融合：

```text
肌电显示准备发力
+ 肩部姿态开始变化
+ 视线锁定目标
+ 足底重心转移
→ 系统推断“准备向右前方挥击”
```

系统输出不只是动作类别，还包括：

- 意图置信度；
- 预计方向；
- 预计力度；
- 紧急程度；
- 人体疲劳；
- 是否可能误触发。

## 控制权融合

```text
人类输入：目标、意图、风格和中止
AI输入：平衡、轨迹、环境、风险和动力优化
硬件输入：机械极限、温度、能源和急停
```

三者冲突时：

1. 硬件生命安全边界最高；
2. 人类中止权高于普通自动动作；
3. AI可以阻止明显会立即伤害操作者的动作；
4. 高风险模式需预授权和明确场所；
5. 控制权变化必须通过触觉、声音或视觉让人感知。

## 扩展身体图式

真正的人机共融要求人逐渐形成：

> “不是我在操作外部机器，而是这套机械结构已经成为我的身体边界。”

这需要：

- 可预测的低延迟响应；
- 一致的方向和比例映射；
- 触觉与力反馈；
- 个体化校准；
- 长期训练；
- AI辅助程度稳定且可解释；
- 错误时不会突然抢夺控制权。

## 首个可验证问题

不是先追求巨大力量，而是验证：

> 能否用安全外部传感器，在虚拟环境中稳定识别少量动作意图，并让用户感觉控制自然、可预测、可随时停止。
