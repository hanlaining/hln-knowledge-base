# 仙武文明计划

> 以人类为文明主导者，以分层认知网络为文明神经系统，以自主机器人为物质执行层，以外附式人机共融机甲扩展人的身体，以可组合“功法”承载技能，并通过机制设计让自动化收益普惠全体社会成员。

## 创始底层原则

> 一切的前提都是机制 体系

以上保留为创始原话。技术、AI、机器人、机甲、商业和文明愿景能否成立，都取决于机制与体系能否先形成正确、顺畅、可持续的闭环。

## 当前定位

这是一个**可持续迭代的构想与研究知识库**，不是已经落地的工程项目，也不是对未来必然结果的断言。

知识库同时容纳四类内容：

- **愿景**：我们希望创造什么样的文明；
- **机制**：权力、收益、权限、纠错和转型如何运行；
- **架构**：AI、机器人、机甲、功法和网络如何成为统一系统；
- **假设**：尚未被证实、需要实验或新科学突破的内容。

## 核心概念

计划暂定的专业名称是：

> 神经肌肉—机电—认知融合文明  
> Neuromuscular–Mechatronic–Cognitive Civilization

文化名称是：

> 仙武文明 / 仙武纪元

其文明结构为：

```text
人类价值、法律与机制
        ↓
分层主权文明认知网
        ↓
专业AI与智能体集群
        ↓
自主生产、机器人与基础设施
        ↓
人机外附式机甲与功法生态
        ↓
全民松弛但不懈怠的感性时代
```

## 迭代原则

1. 新想法先进入讨论归档或开放问题，不直接当作事实。
2. 重大概念必须标注状态：构想、假设、研究中、原型、已验证、废弃。
3. 机甲平台版本和具体型号分开：平台描述共同能力，型号描述具体用途。
4. AI大脑每个重要版本独立建档，不覆盖旧版本。
5. 每次重要调整都更新变更日志和受影响文档的版本号。
6. 技术可行性、制度合理性和文化想象可以并存，但必须清楚区分。
7. 计划的最终目标不是让机器取代人，而是让人从被迫生存劳动中释放出来。

## 一句话总纲

> 技术决定系统能否行动，架构决定组件能否协同，机制决定力量最终服务于谁；仙武文明的目标，是让人类继续掌握价值、制度和方向，同时让AI、机器人与机甲成为扩展人类自由的文明器官。
