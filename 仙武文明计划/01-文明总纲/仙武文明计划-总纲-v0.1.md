# 仙武文明计划总纲 v0.1

## 一、文明命题

当代被称为“AI时代”，但现阶段主要仍是信息和认知劳动的自动化开端。真正完整的AI文明，应当同时满足：

- AI能够持续感知、规划、执行和自我纠错；
- 大量专业AI可以在统一机制下自主协作；
- 机器人进入能源、制造、物流、农业和重工业；
- 自动化生产力形成稳定的物质闭环；
- 人类通过安全的外附式机甲扩展身体能力；
- 自动化收益能够被社会成员广泛分享；
- 人类继续掌握价值、制度、权限和文明方向。

仙武文明不是“AI统治文明”，而是：

> 人类设计文明框架，AI扩展认知能力，机器人扩展物质执行能力，机甲扩展个人身体能力，机制保证所有力量最终服务于人的自由与成长。

## 二、文明目标

### 1. 从生存劳动中释放

让危险、重复、高负荷和不得不做的劳动逐渐由AI与机器承担。人的生活不再以出售绝大部分时间换取基本生存为默认状态。

### 2. 全民松弛但不懈怠

“松弛”不是停止成长，而是摆脱长期匮乏和强迫节奏；“不懈怠”来自探索、创造、关系、艺术、科研、竞技和文明任务等自主选择。

### 3. 进入感性时代

工业文明强调规模、效率和纪律；仙武文明希望在保留理性与工程能力的同时，让人拥有更多时间发展体验、美感、关系、精神生活和个体道路。

### 4. 人类身体升维

机甲不是替代人的载具，而是人的第二身体。人可以通过意图级控制、共享自主和功法系统扩展力量、感知、行动范围与环境适应能力。

### 5. 文明能力普惠

AI、算力、机器人和机甲不应只成为少数人的权力放大器。制度必须保证新生产力带来的机会、收益和成长通道能够覆盖多数人。

## 三、人类在体系中的角色

| 角色 | 责任 |
| --- | --- |
| 价值定义者 | 决定什么值得追求以及哪些事情不可做 |
| 机制设计者 | 设计权力、激励、收益、权限、监督和纠错 |
| 合法性提供者 | 决定系统凭什么获得行动权限 |
| 框架搭建者 | 将各个学科、AI和物理设备统一为系统 |
| 创造者 | 发明功法、角色、审美、组织和新生活方式 |
| 监督者 | 发现AI和制度的系统性偏差并修正 |
| 体验者 | 文明生产力最终服务的生命主体 |

## 五、文明边界

仙武文明计划当前坚持：

1. AI不能成为未经人类授权的最终价值来源；
2. 高度自主不等于无限权限；
3. 内容可以依法分级保密，但权力必须有边界和监督；
4. 技术进步不能以大规模个人承担转型成本为默认代价；
5. 机甲和功法必须具备硬件级安全边界；
6. 机器人主观意识是否存在保持开放，不把拟人表现当作科学证明；
7. 尚未发现的能源、材料和防护技术必须明确标注为假设；
8. 计划既允许浪漫想象，也要求工程记录保持诚实。

## 六、文明阶段

### 第一阶段：智能体时代

AI能够在软件世界中长期规划、调用工具、协同工作并接受审计。

### 第二阶段：具身工业时代

AI进入机器人、工厂、物流、能源和重工业，形成高度自主的物质生产能力。

### 第三阶段：人机共生时代

安全外附机甲、共享自主和具身功法使机器成为人的扩展身体。

### 第四阶段：仙武纪元

自动化红利普惠，人的主要生活从被迫生存劳动转向创造、体验、探索与自我道路；虚拟与现实的功法、机甲和文明网络形成完整生态。

## 七、核心判断

> 仙武文明真正困难的部分不是某一个模型、传感器或材料，而是将技术、组织、权力、经济和人的体验统一成一个长期稳定的文明个体。
