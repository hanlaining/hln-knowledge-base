# 前端交付合同

## 输入

- 冻结 Figma file/node 与截图。
- 页面/状态/交互验收脚本。
- 项目设计 Token 和组件规则。
- 冻结服务合同。

## Evidence

- 同 viewport 的 Figma 与真实浏览器截图。
- 视觉差异结论：布局、字体、色彩、资产、状态。
- hover/focus/disabled/loading/error/无权限。
- keyboard、a11y、responsive、reduced motion。
- 真实 API 成功与失败状态；mock 只能作为单测辅助。
- 测试命令、退出码、totals、完整 diff Review。

## 阻塞

Figma 与项目 Token 冲突、合同缺字段或资产缺失时写明选择并请求上游决定，不私自制造第二套规范。
