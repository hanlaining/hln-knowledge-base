# 参考项目评估

## 产品适配

- 目标用户与当前产品是否相似。
- 最短任务与关键阻力是否相似。
- 页面密度、设备、协作和权限边界是否相似。
- 借鉴内容能否明确映射 Rxx/ACxx。

## GitHub 事实

- 仓库、Demo、最近 release/commit 和维护者事实。
- LICENSE 类型、依赖许可证和商用限制。
- issue/PR 活跃、测试、CI、依赖锁定和安全记录。
- 是否需要账号、付费服务或不可信外部端点。

## 结论

只输出 `adopt`、`adapt`、`reference`、`reject`。每个结论给事实证据、适配理由、必须移除项和风险；不使用“很火”“很高级”作为判断。
